# 第八章：案例分析——品牌账号如何运营

## Core Idea
品牌账号爆款笔记可归纳为**七大类**：抽奖福利类、用户共创类、品牌联动类、热点营销类、玩梗人设类、产品联名类、玩梗卖货类。有效公式是 **内容有趣味性 + 玩梗恰到好处 + 有共鸣点**。

> 老乡鸡与洁柔的完整爆款清单见 [ch08-cases-reference.md](ch08-cases-reference.md)。

## Frameworks Introduced

- **七大爆款类型与公式**：

| # | 类型 | 爆文公式 |
|---|---|---|
| 1 | 抽奖福利类 | 预热 + 玩梗抽奖 + 引流 |
| 2 | 用户共创类 | 回应 + 实时共创过程 + 产品推出 |
| 3 | 品牌联动类 | 抓住热点 + 玩梗联动 |
| 4 | 热点营销类 | 抓住热点 + 玩梗联动 |
| 5 | 玩梗人设类 | 趣味性玩梗 + 帅哥变装 + 霸总宠粉人设 |
| 6 | 产品联名类 | 联名过程 + 征求粉丝建议 + 产品推出 |
| 7 | 玩梗卖货类 | 趣味性玩梗 + 带货链接 |

- **五类爆款标题公式**（从洁柔前 10 篇爆款笔记统计归纳）：
  1. **直球式**："抽 1 位马铃薯公主送去哈尔滨"——开门见山、简单明确。
  2. **紧迫感式**："免费的华为全家桶，就在今天！！"——让用户感觉现在不点进去就会错过。公式"×××，就在今天（现在）"在前 10 篇爆款中出现 5 次，且排名都在前 5 位。
  3. **玄学/锦鲤式**："被霸总指到的人都中奖！""××礼物就是你的"——制造"我刷到就中奖"的错觉。
  4. **态度宣告式**："×××，霸总第一个举手"——直白告诉用户我们行动力强、真听劝。
  5. **共创宣告式**："因为一条笔记，洁柔的纸巾要改版了？！""接下来，你一定会收到梦想的录取通知书！"
- **封面三法**：**大字海报**（把奖金/礼品/信息直接压在图上，加"免费""可折现"字样）、**实拍图**（增加真实感，拉近用户距离）、**用户帖子截图**（证明"我们在看用户需求"）。
- **营销 4.0 阶段**：1.0 上央视 → 2.0 多屏幕 → 3.0 相信人（明星/KOL 推荐）→ 4.0 **算法 + 口碑**（年轻消费者做决策前先去小红书搜）。
- **品牌做号五法（千瓜专访总结）**：①账号人设与核心内容规划；②贯彻品牌年轻化战略（善于玩梗、造梗）；③账号抽奖玩法与私域运营；④运营互动技巧与产品价值打造；⑤爆款研究与品牌联名。
- **品牌账号做得好坏的三个指标**：**官方账号活跃度、品牌相关笔记数、品牌爆文笔记数**（一和三尤其重要）。
- **品牌人设的建立三步法**：①研究品牌在社交媒体上的"自来水"，总结受众讨论的核心；②找到核心与互联网年轻化的结合点（引入可参与讨论的社会化话题）；③把社会化话题受众与品牌受众做**三方交集**，再放大并树立人设。

## Key Concepts

- **"抽×位×××公主送去×"**：把普通抽奖包装成身份特权与奇观。
- **抽前预告 > 抽奖本身**：洁柔第一个 iPad 还没开始抽就涨粉 4 万多，真正抽奖时反而没涨多少。
- **抽奖是内容的 1/10，不是 1/2**：先把人设和内容打磨好，再做抽奖。
- **做第一个，不做第二个**：热点跟进的第一品牌获得全部注意力。
- **不能做热点的穿堂风，更不能做热点的神经病**——"要么玩得好，要么玩完"。
- **囤货感封面**：把很多纸摞在一起，制造囤货感，这类封面容易成为爆款并带来涨粉。
- **与用户做朋友**：回复时用人设语气互动，回复本身也在创造新的梗。
- **抽奖只做 1/10**：盲目抽奖涨粉快但掉粉快，除抽奖外其他内容无人问津。

## Mental Models

- **Use 共创 when 快速拉近距离**：低成本的品牌与用户互动方式，还能产出内容灵感。
- **Use 联名 when 需要破圈**：只有**有热度/话题性高的 IP** 才值得联名，没热度的 IP 联名对品牌没帮助。
- **Think of 品牌 as 一个 IP**：在用户心中让品牌"有一张脸"，比同质化的纸更被购买。
- **Use 三方交集 when 立人设**：品牌受众 ∩ 社交热点话题受众 ∩ 品牌产品特性，三者交点才是人设。
- **Think of 玩梗 as 参与感**：玩梗不是段子技巧，是给用户一个"共同话题"的入场券。

## Anti-patterns

- **不要靠抽奖当涨粉主引擎**：涨得快掉得也快，除抽奖外其他内容无人问津。
- **不要连发同类型引流贴**：用户会以为"永远不开奖"，产生信任危机。
- **不要和没热度的 IP 联名**。
- **不要硬广推销**：玩梗卖货类要在文案里植入梗，而不是硬广；用户反感品牌做硬广推销。
- **不要做热点的穿堂风或神经病**：跟进但不融入，等于浪费一次热点机会。
- **不要让官方号只看到夸奖**：客诉同样重视。
- **不要被工具反噬**：抽奖只是涨粉手段之一，核心是打造有内容价值的宣传渠道。

## Worked Example

**洁柔官方号两个月战绩**：借"霸总"人设揽粉 8 万+，产出爆文笔记 20 篇，现矩阵粉丝 200 多万，是快消品官方账号中粉丝数非常多的品牌之一。

**人设是怎么立起来的（洁柔）**：①"自来水"——古龙香黑face手帕纸被大众讨论"香味像某大牌香水"，相关笔记互动数据高；②结合点——霸道总裁小说都提古龙香，#霸道总裁 在小红书话题浏览总量高达 1.63 亿；③三方交集——霸总梗流行于年轻女性，洁柔受众女粉占 93.56%、18–24 岁占 48.86% → 确立"霸道总裁"人设，写好人物小传："很少人见过他，但到处都是他的传说，古龙水、黑face、一抽搞定……据说谁要关注他，这辈子都不缺纸。"

**千瓜专访的五点方法（吕白）**

1. **账号人设与核心内容规划**——树立品牌人设，构建"人物小传"，研究平台用户关注焦点，挖掘与人设产生交集的热门话题方向。
2. **贯彻品牌年轻化战略**——善于玩梗、造梗，做一个有意思、有内容、有价值的品牌。
3. **抽奖玩法与私域运营**——丰富抽奖预告形式激发活跃度；善用抽奖工具但不依赖；用私域拉近关系（建粉丝群做冷启动，让粉丝每天为品牌说话形成正向循环）。
4. **运营互动技巧与产品价值打造**——和用户做朋友，听取建议并及时反馈，给产品赋予情绪价值，从互动中获取内容灵感。
5. **爆款研究与品牌联名**——深耕行业底层，加入行业群与同行交流，研究标杆爆款（"很多爆款内容往往都是重复的"），通过联名实现共赢。

## Key Takeaways

1. 品牌爆款七大类：抽奖福利、用户共创、品牌联动、热点营销、玩梗人设、产品联名、玩梗卖货。
2. 标题五型：直球式、紧迫感式、玄学式、态度宣告式、共创宣告式。
3. 封面三法：大字海报、实拍图、用户帖子截图。
4. 抽奖是内容的 1/10；抽前预告比抽奖本身更涨粉。
5. 做热点的第一个，不做第二个；不能做穿堂风也不能做神经病。
6. 立人设走"自来水 → 社会化话题 → 三方交集"三步。
7. 品牌做号五指标：活跃度、相关笔记数、爆文笔记数。
