# 第六章：商家获客——4 大类目线上获客打法

## Core Idea
线下商家做小红书，围绕同样三类内容（流量类、案例类、人设类）和三种流量打转。优质笔记能同时完成**引流、营销、立人设**三件事——三者并不割裂。

## Frameworks Introduced

- **商家内容三分法**：
  - **流量类内容**：主打干货爆款，短时间引爆账号流量，吸引对该话题感兴趣的人关注。
  - **案例类内容**：凸显服务专业性拉升信任；主要是商业成功案例——**用户服务前后对比**、**用户真实好评反馈**，能直接激活潜在客户。
  - **人设类内容**：公司十年介绍、服务过多少客户、接触多少行业、标杆案例、创业故事；数据不高，但让潜在客户点进主页那一刻就把需求与服务对上。
- **四类目打法**：婚纱 / 民宿 / 文绣 / 留学。每个类目给出：竞对分析 → 流量类选题与爆款标题 → 案例类呈现形式 → 人设类呈现形式。
- **双引擎打开笔记的两个关键点**：小红书是双向瀑布流，**用户是否点开取决于两件事——封面够不够吸引人、标题是否"抓人"**。
- **留学赛道的特殊逻辑（弱化机构形象）**：大众本能抵触机构、怀疑营销广告；正确做法是**以学长、学姐、留学申请老师或机构创始人的身份输出**，信任感与权威性更强。高客单价必须靠信任基础，干巴巴的干货知识做不到。
- **矩阵思维**：当你清楚账号从起号→咨询→转化成交的全链路，就能搭建矩阵，用**频次对抗单账号的不确定性**。

## Key Concepts

- **用户服务前后对比**：案例类内容里最硬的信任资产。
- **用户好评反馈**：成本低且利于转化；可把内容和评论区做成好评反馈图。
- **线下实景与服务流程展示**：让用户看到"到店后会发生什么"。
- **标签强化**：民宿类目要强化"大理民宿""云南民宿"这类地域标签。
- **内容即产品，产品即营销**：一篇笔记在制作的那一刻就同时完成了产品介绍与营销使命。
- **矩阵号**：用多个账号增加内容曝光度，用频次对冲单账号波动。

## Mental Models

- **Use 案例内容 when 临门转化**：用户已在看你的账号，需要的是"别人做到了"的证据。
- **Use 人设内容 when 主页承接**：用户点进主页 3 秒内要完成"我需要 → 你能做"的匹配。
- **Think of 封面+标题 as 双重门**：两个都弱，内容再好也不会被点开。
- **Think of 机构 vs 个人 as 信任差**：留学这类高客单赛道，先做人再做机构。
- **Use 矩阵 when 单号数据不稳**：用频次对冲不确定性。

## Anti-patterns

- **不要只发店铺美照**：民宿老板发了许多条民宿照片都没人看——照片要能产生"向往"，且必须配标签与干货。
- **不要干瘪地"利他"却没转化**：留学机构努力做利他内容，数据仍不起色，原因是缺乏信任基础。
- **不要用机构口吻做个人 IP**：机构账号要与用户有"像朋友一样"的关系。
- **不要忽视转化链路**：做账号前必须想清楚变现路径、目标客户画像、痛点、成交方式。

## Worked Example

**四大类目详解**

**一、婚纱类目**
- 案例类呈现形式：①婚纱礼服展示；②用户好评反馈；③线下店面情况及具体服务流程展示。
- 人设类（婚纱店主理人账号）：创业开婚纱店的心路历程、婚纱店主理人的一天都在忙什么、主理人如何选品、一个普通女孩开婚纱店的十年经历。
- 人设类（礼服师账号）：记录一天工作日常、分享从业多年感悟、给新人选婚纱遇到的感人故事、揭秘选婚纱的一些套路。
- 爆款标题五类：直球式、紧迫感式、玄学式等（详见 Ch8 标题公式）。

**二、民宿类目**
- 前期先积攒民宿美照素材（后续成为内容的一部分），并强化地域标签。
- 案例类：①线下实景展示；②用户与店家的互动（可适当玩梗）。
- 人设类：创业开民宿的心路历程、民宿主理人的一天生活记录、普通女孩开民宿的十年经历；可展示客户好评、拍周边环境，并在和客户聊天记录里埋梗引发大众传播。

**三、文绣类目**
- 流量类多为文眉干货，图文或视频均可。
- 案例类：①用户眉毛服务前后对比示例；②用户体验后的好评反馈；③线下店面情况与服务流程展示。
- 人设类（文绣师）：创业开文绣店心路历程、做文绣师十余年的套路揭秘、文绣师的一天、普通女孩的文绣十年经历、文绣师月入十万的成交经验。
- 人设类（文绣机构）：机构成立多少年、创立初心、服务过多少客户、用户好评数量、连锁门店数、店面环境、文绣师从业年限。

**四、留学赛道（低粉高变现）**
- 案例类：一篇好笔记能实现流量、营销、人设全方位覆盖；用户好评反馈为"你能提供价值"持续背书。
- 人设类：让别人对你的生活状态产生向往——逆袭人生（双非一本到独自海外留学创业）、学霸故事。

**商家自检五问（作者给出的通用思考框架）**

1. 我的商业变现路径是什么？
2. 我的目标客户人群画像是什么？
3. 我的目标客户的痛点是什么？
4. 围绕客户的痛点问题如何输出内容？流量类内容怎么输出？营销和人设类内容又如何输出？
5. 当你有精准客户咨询时如何转化成交？

**学员验证案例**：@粽子de野生眉 按建议做了"文眉前必看，6 大文眉避坑指南"的视频笔记，单条 3000+ 点赞，既拉升账号流量，又收获大量私信，很快完成获客目标。→ 干货类内容能在潜在客户处获得充分曝光。

## Key Takeaways

1. 商家同样只做三类内容：流量类引流、案例类激活需求、人设类建立专业信任。
2. 案例类内容的三个硬通货：前后对比、用户好评、服务流程展示。
3. 封面和标题是打开笔记的两道门，缺一不可。
4. 高客单赛道（留学）必须弱化机构、做个人 IP。
5. 民宿类目先积素材 + 强化标签；文绣类目靠"避坑指南"类干货起量。
6. 想清楚从起号到咨询到成交的全链路，再用矩阵用频次对冲风险。
