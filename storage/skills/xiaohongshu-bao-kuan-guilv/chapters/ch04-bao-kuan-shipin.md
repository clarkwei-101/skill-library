# 第四章：爆款视频——让你的视频上热门

## Core Idea
**前五秒留不住用户，爆款就跟你没关系了。** 视频爆款 = 选题 + 封面 + 文案 + 表现力 + 标题，五个里面至少三个做对就能火；网感靠刷低粉爆款和拆爆款练出来。

## Frameworks Introduced

- **网感三练法**：
  1. **大量刷低粉爆款**（用千瓜数据、新红的低粉爆款排行）——别人可以忽略低粉，你必须关注。起号前一周每天至少花 3 小时刷短视频，重点思考**前五秒如何吸引人**。
  2. **大量拆爆款**——按类型拆：剧情视频拆开场，vlog 拆选题，口播拆"钩子"和开头。坚持一个月流量至少提高 50%。
  3. **先猜评论，再看评论**——排在前面的往往是能引起争议的评论，因为争议带来互动数据，互动让视频爆。所以写脚本时要**刻意设置观众讨论点**。
- **爆款要素公式**：选题 + 封面 + 文案 + 表现力 + 标题；**至少三个不错就能火**。
- **三点布光**：主光（侧前方约 45°，向下柔光，光心在胸口）+ 辅助光（侧前方 45–65°，向下柔光）+ 轮廓光（侧后方，高于摄像机）；可再加背景灯。
- **光线优先级**：室外自然光 ＞ 室内自然光（朝窗户）+ 补光 ＞ 补光。
- **五景别**：远景 / 全景 / 中景（膝盖以上，口播常用，有亲切感）/ 近景（胸部以上，展现性格情绪）/ 特写（肩部以上，放大表情，交代细节）。
- **剪映口播视频标准流程**：导入素材 → 智能剪口播 → 智能字幕 → 添加花字 → 添加音效 → 导出设置。**第一步先在设置里关掉"自动添加片尾"**，否则会带其他平台水印影响小红书推荐。
- **镜头表现力的本质**：不是夸张咆哮，而是"你能多大程度自然地做自己"。

## Key Concepts

- **沟通公式**：沟通 = 7% 语言 + 38% 声音 + 55% 肢体动作 → 转化为镜头表现力。
- **景别**：焦距一定时相机与对象距离造成的呈现范围差异。
- **曝光三要素**：ISO（感光度）、S（快门速度）、EV（曝光补偿）。
- **对焦三模式**：AF-S 自动单次 / AF-C 连续自动 / MF 手动。
- **白平衡 AWB**：阴天 / 荧光灯 / 白炽灯 / 晴天 / 自定义。
- **收音**：尽量靠近录音对象、选安静环境、关闭噪声设备；预算 500 元内选有线，1000 元左右猛犸 1 拖 2，2000 元左右罗德；常用领夹式（Lavalier）麦克风。
- **设备**：桌面三脚架（50 元以下）、落地三脚架（通常与补光灯同售）。
- **手机拍摄推荐**：1080p、16:9、30fps；iPhone 选"兼容性最佳"格式、开启九宫格与镜像前置；拍摄前务必擦镜头。

## Mental Models

- **Use 低粉爆款库 when 判断选题**：同样的低粉，他们火了你没火 → 问题在选题或前五秒，去分析背后的逻辑。
- **Think of 争议 as 燃料**：故意在脚本里埋一个可争论的点。
- **Think of 前五秒 as 一次性筛选器**：它不是加分项，是及格线。
- **Think of 景别 as 情绪旋钮**：讲叙事用中景，讲情绪用近景，讲细节用特写。
- **Use 猜评论法 when 写脚本**：先写下"用户会怎么反驳"，再决定观点立场。

## Anti-patterns

- **不要只做精致不做信息密度**：封面密密麻麻、信息密度大在小红书更容易火（见 Ch2 粑粑人案例）。
- **不要用 4K**：画质虽高但太占内存、后期极慢（曾导出花掉近一天）。
- **不要在室内自然光不够时只靠一盏灯**：容易出"死亡光线"，画面暗沉不自然。
- **不要用激烈节奏的背景音乐**：分享书籍/知识类内容用舒缓或轻快纯音乐，音量约 -20 分贝；人声拉高 10–15 个点并统一开启降噪。
- **不要靠提词器逐字念稿**：会变成"只会读稿的机器人"。要熟悉稿子、理解断句重读轻读。
- **不要开太多音效**：恰到好处即可，太吵显得廉价。

## Worked Example

**剪映口播视频剪辑参数参考（作者本人实操）**

- **字体**：点宋体、优设标题；字号 12–18；高度位置 y ≈ -900。强调关键词用"黄色"或"红色"预设样式或花字；入场动画用"缩小""收拢""甩出"。
- **背景音乐与音效**：书籍类用舒缓/轻快纯音乐，音量约 -20 分贝；个人成长与工具分享类用节奏渐进增强型（"大气磅礴"），同样避免盖过人声。音效从"综艺"类目取（冒泡、水滴、金币、小孩哭泣），在需强调的字幕处添加。
- **画面调节**：亮度 5–10；锐化 30–40；对比度 ≤10；开启肤色保护；磨皮 ≥70%、美白 ≥50%、瘦脸 50–80%、下颌骨 ≥70%。
- **导出**：1080p，30 或 60 帧，mp4，H.264，码率默认。

**摆脱镜头尴尬症四步**

1. **熟悉稿子**：不依赖提词器；多读几遍，理解断句、重读轻读、语气；对镜练习，目标是强烈信任感。
2. **找好环境**：选舒适、安静、有安全感的地方；拍摄前热场；局促时用抱枕、书籍等道具增强安全感。
3. **把镜头当眼睛**：想成在跟你日常频繁沟通的人交流，用眼神说话。
4. **拍完复盘**：及时看视频并修改；每次总结问题；把文字交流变成语音交流，每天录一条。

**拍摄设备参数速查（华为专业模式）**：矩阵测光（风景/街道）、中央重点测光（主体在画面中部）、点测光（舞台、人物特写）；ISO 室内 100–200、室外 400、夜景 400–800；EV 范围 -4.0–4.0；AWB 偏黄暖调调高色温 K 值，偏蓝冷调降低 K 值。

## Key Takeaways

1. 前五秒是及格线，起号前一周每天刷 3 小时低粉爆款。
2. 爆款 = 选题 + 封面 + 文案 + 表现力 + 标题，五项中三项做好即可。
3. 刻意埋争议点能提升互动数据。
4. 自然光优先，室外自然光 ＞ 室内自然光+补光 ＞ 补光；先学三点布光。
5. 剪映六步流程能剪出第一条爆款视频，第一件事是关掉自动片尾。
6. 镜头表现力 = 自然地做自己，靠四步刻意练习，而不是靠夸张。
7. 口播视频按模板调参：字体 12–18、亮度 5–10、锐化 30–40、音量 -20 分贝。
