# 第三章：爆款规律——小红书文案这么写才会爆

## Core Idea
提升文案功底的核心就三个字：**拆爆款**。所有爆款文案都可以拆成**开头、主体、结尾**三部分——分别拆解开头如何吸引人、正文如何陈述观点、结尾如何升华与互动。本章给出 9 种开头 + 2 大主体 + 5 种结尾模板。

## Frameworks Introduced

- **文案三段拆解法**：开头 → 主体 → 结尾，拆解时"一定不要单纯地陷入内容中去，而是带着思考去拆解"。拆完必须**复盘总结**，按复盘方法论写自己的笔记。
- **9 种吸睛开头**：

| # | 类型 | 模板 | 作用机制 |
|---|---|---|---|
| 1 | 呈现结果型 | 直接晒成果/变化 | 激发好奇心，产生跟随冲动 |
| 2 | 罗列痛点型 | 揭露用户的"痛" + 给出解决方案 + 解决效果 | 对号入座（"怕上火喝王老吉"） |
| 3 | 引起恐慌型 | 罗列痛点问题 + 不改变的巨大不良后果 + 致以改变的具体方法 | 恐惧 = 害怕失去 + 对未知的不确定性 |
| 4 | 提问型 | 提问 + 回答问题 / 提问 + 讲故事 | 把注意力带进问题，边思考边产生好奇 |
| 5 | 讲故事型 | 时间地点人物 + 事件 + 引出话题 | 用户做故事旁观者，消解锋利感 |
| 6 | 场景呈现型 | 描述"拥有后的美好画面"或"没有后的糟糕画面" | 让用户产生画面感与需求 |
| 7 | 反常识型 | 打破大众固有认知的观点 | 观点不唯一，逻辑自洽即可 |
| 8 | 制造冲突型 | "硬组合"：两个大众认知中无法共存的词 | 冲突越大，话题越大 |
| 9 | 直入正题型 | 主题 + 能带来的价值 + 互动 | 快速让用户知道主题与收益 |

- **恐慌诱导法的四个生效条件**（《认知操纵》）：①足够吓人；②能提供具体战胜威胁的建议；③使消费者相信提供的建议能降低威胁；④用户执行建议时很方便。
- **2 大主体模板**：
  - **列点式**：点与点平行，侧重阐述要素（第一…第二…），条理清晰。
  - **递进式**：点与点有先后承接（是什么+为什么+怎么样 / 案例+原因+解决方案 / 第一步+第二步+第三步）。
- **5 种结尾模板**：
  1. **金句升华**（配合峰终定律）——建议专门准备"金句本"，收藏句子控、句子迷
  2. **美好祝福**（与故事寄语型结尾同类）
  3. **互动提问**（拉数据、引评论；用户喜欢内容但会忘记点赞，需提醒）
  4. **总结回顾**（用表格或思维导图回顾，拉回主题 + 制造"截图保存"冲动，**提升收藏数据**）
  5. **号召行动**（教程类笔记专用，"完成比完美更重要"）

## Key Concepts

- **峰终定律**（卡尼曼）："峰"与"终"的体验给大脑留下深刻印象，其余细节被遗忘 → 好的结尾拉升互动率、推动曝光。
- **三大情绪**：愉悦、痛苦、恐惧（梁宁：一个人的底层操作系统是情绪）。
- **黄金一小时**：起床后黄金一小时，是被市场多次验证的爆款选题（复盘一姐靠它获赞 20 万、收藏 15 万）。
- **专业杀死流量，演员成就爆款**（贯穿全书的表达力原则）。
- **小白起步禁忌**：一上来"哈喽，大家好，我是某某某"式自我介绍开头，在没有粉丝基础的前期太不抓人。
- **利他自检**：我账号的用户画像是什么？他们对这个选题主要想了解什么？同类型选题别人讲了什么？我有哪些优化空间？如果我是用户，我对这篇笔记是否满意？

## Mental Models

- **Use 结果型开头 when 你有成绩可展示**：任何"变化"都能当作开头。
- **Use 恐慌型开头 when 痛点严重**：但必须紧跟"可复制、可执行"的方法，否则只产生不适感。
- **Use 故事型开头 when 话题带锋利性**：直接提问会显得说教，讲故事能让用户成为旁观者，拉近心理距离。
- **Use 反常识型开头 when 所有人都在说同一件事**（如都在讲"自信有多美"，你就写《昂首挺胸地自卑吧》）。
- **Think of 结论 as 曝光位**：用户点进来 3 秒内看不到主题和价值，会立刻划走。
- **Think of 收藏 as 内容的二次分发**：思维导图/表格结尾能提升收藏率。

## Anti-patterns

- **不要陷入内容本身去拆**：拆解必须带思考，否则只是在读稿。
- **不要只会用一种开头**：9 种模板要按选题切换。
- **不要只制造恐慌不给方案**："一篇文案不能光有恐慌，那样会让人产生强烈的不适感。"
- **不要用纯列点式表达有先后关系的内容**：点与点需要递进时用列点式会让逻辑断裂。
- **不要在结尾写没有信息量的总结**：普通总结不如思维导图/表格。

## Worked Example

**罗列痛点型开头的完整拆解（《起床后黄金一小时》，复盘一姐，20 万赞）**

1. **对号入座**："起床后就打开手机的朋友们，看到这条视频，说明上天在提醒你要开始改变了。" ——"对号"可以是坏习惯、症状，也可以是渴望（想挣钱变美、习惯性内耗）。
2. **讲痛点（点出隐蔽后果）**："你以为你只是正常看一下新闻，其实你消耗掉的是你一天当中最宝贵的时间。"——表面无害的习惯造成巨大后果。
3. **给方法 + 呈现效果**："正因为利用好了起床后的一个小时，我在大学期间不仅保证了学业第一，还把我的学生会工作做得引来了省教育电视台专题报道……28 岁我就开始创业，走过 36 国。挣到 1000 万，然后结婚，继续深造。"

**迁移模板**：如果你是旅游攻略博主 → "所有国庆节打算来北京旅游的朋友们，刷到这条视频，就是上天在提醒你这个假期有很多可以玩的东西。旅游前密密麻麻地做足了功课，看够了攻略，但脑子还是一团糨糊。不是你不用心，是你不懂怎么做攻略。正因为我用了这套做攻略的方法，我出去旅游都跟到自己城市一样，熟门熟路。"

**引起恐慌型开头（《三多同学》）**

- 罗列痛点：晚上不睡、早上不起、只想玩手机、一边焦虑一边继续玩。
- 巨大后果："记性越来越差，做事越来越慢，注意力无法集中，表达能力退化，没干啥就觉得好累，对整个人生失去掌控感。"→ 这是引起恐慌的部分。
- 致以方法："以下方法曾帮助我走出摆烂困境，快速恢复学习力和执行力。"

**逻辑的迁移示例（理财赛道）**："一到月底就月光，努力工作大半年，口袋里还是只有几个钢镚……你难道一点都不焦虑吗？再这样无计划消费，你和同龄人的差距将越来越大。不过先别慌，以下几个方法可以帮你建立良好的消费观。"

## Key Takeaways

1. 拆爆款是练文案的唯一路径，拆的是"开头/主体/结尾"三段的结构，不是文案的辞藻。
2. 9 种开头各有机制，按选题和用户情绪选；罗列痛点型最通用。
3. 恐慌型开头必须配"具体、可复制、用户执行方便"的建议。
4. 主体只有两种骨架：列点式（平行）与递进式（有先后），掌握这两种能应对 90% 选题。
5. 结尾要拉互动率与收藏：互动提问拉评论，思维导图结尾拉收藏。
6. 好的金句准备靠日常积累（金句本 + 句子控/句子迷），不是临场编。
7. AI 可以批量生成种草文案，但要按"角色 + 需求 + 模板"自由模式输入再人工修改。
