# 第八章附录：老乡鸡与洁柔爆款笔记清单

## 一、老乡鸡账号爆款笔记分析

### （一）抽奖福利类
1. **豪气** — 数量大、金额非常高。
2. **紧跟当下热点** — 结合国庆、五一长假抽旅游基金，情人节送花，高考结束后送旅游金；"××搭子"热词盛行时，抽"工作内容简单但工资高的小红鸡助理"作为奖品。
3. **引流方式新颖** — 使用肯德基的"疯狂星期四"发疯文学；敲董事长的门、拿董事长的钱包给粉丝抽奖；用户共创（"我在大润发杀鱼的梗 + 抽奖给钱替上班"）。
4. **大奖中奖公示** — 坐实宠粉人设，为新抽奖引流。
5. **日常爱抽包括但不限于自己公司产品的小奖** — 肯德基"疯狂星期四"、王者荣耀皮肤、1000 元老乡鸡卡；手抽小奖在评论区公示，@中奖者并置顶评论。
- **总结**：抽奖图片用大字报，标题把抽奖数量和金额直观表现出来；大抽奖要紧追热点、做第一人；除大抽奖外还需非本公司产品的小抽奖（如"v50"）。

### （二）用户共创类
1. **搞笑 + 玩梗** — 鸡生鸡蛋（打碎的鸡蛋是鸡的儿子，贴合老乡鸡品牌）；用户发帖问摔断了老乡鸡筷子怎么办是否需要赔偿，老乡鸡直接截图回复不用赔钱，并表示自己也经常不小心摔坏东西，以幽默语气安慰用户。
2. **重视用户 + 表明态度** — 不是只看得见夸奖，客诉也同样重视；拿砖头跑到研发中心询问好吃的菜品怎么总是下架；食品安全问题向从餐食中吃出餐巾纸的用户官方道歉并郑重声明；自查自纠食品安全问题，给消费者一颗定心丸。
3. **饮食健康** — 在用户推动下公布 500 大卡套餐和菜品热量表，契合健康与减脂热点。

### （三）玩梗人设类
- **社会热点** — 高考录取填志愿期问"清华好还是北大好"；发文表示分数达到 784 分怎么进不了复旦大学（原来芝麻信用分）；高考出成绩后收留高考心碎男孩并配土味大字海报；春节上春晚用"我在大润发杀鱼"梗；疯狂星期四用发疯文学"v我 50，让我们一起谢谢鸡"；给董事长报名《男生女生向前冲》并配"怎么也飞不出，花花的世界"；董事长开会嗑瓜子如何提醒他；老板画大饼；老乡鸡收藏夹都是帅哥；职场高情商。
- **品牌联动** — 老乡鸡咯咯嗒 × 周黑鸭嘎嘎嘎 CP 梗；官方号点名盒马（招牌少字）和星巴克（洒地上了）互动。
- **公益** — 免费提供米饭；物资捐赠。
- **用户共创** — 借"我在大润发杀鱼"的梗，玩"给钱替我上班"的游戏。
- **官方联动** — 将董事长与老母鸡 P 图在一起，在小红书官方主题下玩梗。
- **抽奖小卡片** — 老乡鸡卡；定位汤臣一品；共享单车"限量版法拉利"；敲董事长的门拿董事长的钱包抽奖。
- **其他** — 名字梗；CP 梗（奥特曼"你相信光吗"、把开店通知包装成机密文件）；疯狂下属。

## 二、洁柔账号爆款笔记分析

### （一）抽奖福利类
**爆文公式：预热 + 玩梗抽奖 + 引流**
- 抽奖礼品：华为全家桶、华为 mate 60、iPhone 15、iPad、5000 元哈尔滨旅游基金、1 万元旅游基金、1 年纸巾自由等。
- 派送福利：定期派纸、新品试用、香水、霸总周边、铁粉礼等。

**案例 1｜旅游基金（现金）抽奖**
- 标题：抽 1 位马铃薯公主送去哈尔滨
- 数据：4 万点赞、1.8 万收藏、80560 评论
- 爆点：①**直球式标题**——"抽×位马铃薯公主送去×"，简单明确 ②**大字海报**——明确"可折现 5k"，对用户有价值，多方位吸引用户群体，引发好奇心 ③**热点**——近期哈尔滨热度高，用户会向往去玩、凑热闹
- 同类内容缺点：缺乏热点玩梗、内容单调；金额虽大但没体现"可折现"（用户对现金期望度高）；都提到要求，而"马铃薯公主"没有要求，相对更直观简洁。

**案例 2｜礼品、产品抽奖**
- 标题：免费的华为全家桶，就在今天！！
- 数据：2.1 万点赞、1.2 万收藏、31163 评论
- 爆点：①**紧迫感标题**——"×××，就在今天（现在）"体现抽奖送福利的紧迫性 ②**封面开门见山**——直接上赠送礼品图，所见即所得 ③**豪气**——礼品多且金额大，实用性强
- 同类内容缺点："正在送×××"缺乏紧迫感；礼品不够吸引眼球，可考虑送大奖或高吸引力实用礼品；缺乏热点与玩梗内容衔接。
- 总结：紧迫感标题公式在前 10 篇爆款笔记里出现 5 次，且排名在前 5 位；大字海报把抽奖产品直接放在图片上，加"免费"字样。

**案例 3｜抽奖引流**
- 标题：被霸总指到的人都中奖！
- 数据：1008 点赞、258 收藏、656 评论
- 爆点：①**玄学标题**给人"我刷到就中奖"的错觉 ②大字海报，开门见山 ③内容有引导互动性，锦鲤类内容吸引力高
- 同类内容缺点：连续更新同一类型引流贴会降低用户兴趣并引发信任危机（"一直宣发抽奖但不开奖"的感觉）；图片仅做引导性、缺乏趣味性。

### （二）用户共创类
**爆文公式：回应 + 实时共创过程 + 产品推出**
共创内容：纸巾改版（五层改四层）、香水、美术生、洗不烂纸巾、草间弥生等。

1. **纸巾改版** —《因为一条笔记，洁柔的纸巾要改版了？！》4245 赞、296 收藏、1753 评论。爆点：标题"因为×××，我们要改版（出新品）啦"直观告诉用户"我们执行了，就是宠粉"；封面采用当时热度最高的图片，视觉冲击力大；内容互动性强，询问意见，让用户有发言权。
2. **香水共创** —《他们卖的香水，好像是从我这免费进货的》3098 赞、823 收藏、1520 评论。爆点：玩梗卖惨，直观告诉用户已出香水且被闲鱼倒卖；封面用闲鱼倒卖截图，真实性高；内容引流回香水抽奖帖。
3. **高考、美术生联动** —《接下来，你一定会收到梦想的录取通知书！》4203 赞、177 收藏、127 评论。爆点：标题"接下来，你一定会收到×××"给人心灵寄托感；封面采用用户热帖截图，表达洁柔"认真在看用户需求、时刻关注用户、以用户为中心"的霸总人设；承接孔庙祈福 + 高考季热点，传达好运即将降临的愿景。
- **总结**：用户共创是能快速与用户拉近距离的低成本营销方式，更接地气，也能打造"洁柔霸总宠粉"人设。

### （三）品牌联动类
**爆文公式：抓住热点 + 玩梗联动**
联动形式：国货联盟、国货锦鲤礼包等。

1. **国货联盟** —《国货联盟！！霸总第一个举手》1.5 万赞、761 收藏、16469 评论。爆点：标题"×××，霸总第一个举手"告诉用户行动力强；封面用用户意见截图，直白告诉用户"我们真听劝"；内容表明态度，与蓝 V 认证国货品牌联动；热点：在"花西子 79 哪里贵"的流量扶持下联动国货，凝聚力强，粉丝黏性高、转化率高。
2. **国货锦鲤礼包** —《国货锦鲤大礼包，180+ 家只送一人！》2024 赞、1141 收藏、1578 评论。爆点：标题"×××，180+ 家只送一人"引起好奇心；封面奖品数量多、颜色鲜艳抢眼；内容简单明了，表明态度、立好人设，主打宠粉。

### （四）热点营销类
**爆文公式：抓住热点 + 玩梗联动**
1. **蜂花缺箱子国货热** — 花西子事件后蜂花因玩梗出圈，洁柔抓住热点与蜂花互动，创建国货联盟，回应用户以为洁柔是"宝洁"旗下或外国品牌的疑问，顺势关联品牌 45 周年宣传，笔记均过千点赞。
2. **淄博烧烤热** — 2023 年 4 月起话题持续火热。洁柔紧跟热点，到淄博高铁站送纸、用帅哥吸引游客，点赞破 6000，总互动量达 7000。
- **总结**：紧跟热点、做第一个，不做第二个；掌握好蹭热点的度——不能做热点的穿堂风，更不能做热点的神经病，"要么玩得好，要么玩完"。

### （五）玩梗人设类
**爆文公式：趣味性玩梗 + 帅哥变装 + 霸总宠粉人设**
1. **帅哥变装** —《这个游戏你们觉得好玩吗》9125 赞、1092 收藏、358 评论。共发布 11 条，其中 8 条点赞过千、3 条超 400；符合当代年轻人审美，"男色经济"正被众多品牌关注（望山楂、书亦烧仙草、椰树、封神的质子团、河南文旅等）。
2. **霸总宠粉人设** —《请问一下，有人想试用香水吗？》1231 赞、743 收藏、2315 评论。大字报封面"抓×个女人免费试用霸总香水"，加"免费"字样；豪气；文案"抓女人""爱霸总"体现霸总宠粉人设。
3. **品牌声明有趣一点** —《关于"洁柔洗衣液抽检不合格"声明》2510 赞、698 收藏、5382 评论。封面背锅形象有趣有梗；声明简要直述观点，解释到位，事件有议论点，评论 5000+；符合霸总人设，"全网寻用户免费试用新品"引发用户体验心理。

### （六）产品联名类
**爆文公式：联名过程 + 征求粉丝建议 + 产品推出**
联名品牌：霸王茶姬、卡皮巴拉等。
1. **霸总茶姬纸巾盒联名** —《霸总茶姬（限量版）来了！》5646 赞、784 收藏、3798 评论。标题"×××来了"直观告诉用户做出来了，主打宠粉；封面用实拍图增添真实感；霸王茶姬纸巾盒本身自带热度，用户会自己制作，洁柔帮用户做出来自带话题性。
2. **卡皮巴拉产品联名** —《霸总×豚豚=？》2372 赞、804 收藏、1704 评论。封面直接晒出联名设计稿，直观表达联名正在执行；内容征求用户信息，把参与感拉满。
- **总结**：IP 联名要与热度高的 IP 合作；没有热度的 IP 联名对品牌没帮助。

### （七）玩梗卖货类
**爆文公式：趣味性玩梗 + 带货链接**
内容方向：霸总文学、互动性内容等。
1. **繁花的卖货帖** —《你好香，我势必拿下你》1704 赞、420 收藏、285 评论。图片是简单实拍产品图，与文案联系不起来反而捉摸不透，引起好奇心；文案以霸总口吻叙述，内容有趣，能引发讨论。
2. **互动性内容的卖货帖** —《嚯！玩这么大》1135 赞、133 收藏、294 评论。图片放实拍图加"每人仅限免费观看一次"引起好奇心；标题"嚯，玩这么大"有噱头，每个人都有八卦心理；内容简单明了，直球送香水。

## 三、七大爆款类型总纲

1. **抽奖福利类** — 植入热点或玩梗；奖品金额不能决定是否爆，**有趣的抽奖才有效**，结合热点事件关注度更高。
2. **用户共创类** — 重视用户感受，分享共创过程，让用户参与其中；多挖掘 UGC，多做互动性内容，打造宠粉人设。
3. **品牌联动类** — 快速提升品牌影响力与公信力；官方平台也会提供资源，要学会跟紧热点、第一时间拉动品牌。
4. **热点营销类** — 热点事件发生后快速想好"我们品牌可以做什么"；做跟进的第一个品牌。**热点就是流量密码**，蹭热点能满足人们的参与感。
5. **玩梗人设类** — 内容有趣味性，玩梗恰到好处且有共鸣点，才能引起用户互动、提高点击率。
6. **产品联名类** — 联合热度高的 IP；没有热度的 IP 联名对品牌没帮助。
7. **玩梗卖货类** — 可以植入玩梗内容，别做硬广推销，用户反感品牌做硬广；标题要有吸引力或讨论性。
