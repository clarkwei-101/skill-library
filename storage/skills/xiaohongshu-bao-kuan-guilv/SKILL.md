## 核心框架与心智模型

### 1. 总纲：爆款是重复的

> **100% 成功 = 70% 和爆款类似 × 足够多的试验品**
> 找到自己领域的 **500 条爆款**拆解，找共性。

- **Use 拆解 when 选题枯竭**：找 10 条同赛道爆款 → 总结框架共性 → 换自己的经历填充。
- **Think of 爆款 as 概率 × 样本量**：一条不成不是方法错，是试验品不够。
- **头部思维**：成为**细分赛道里的第一**，不是全平台第一。
- **围棋高手 80% 的时间在"研究棋谱"**：固定给拆解/研究分配时间。
- **不要挑战大众的认知**（《定位》）：定位是操控心智中已存在的认知，不是创造新事物。

### 2. 三种流量，三种逻辑

| 流量 | 定义 | 与变现的关系 |
|---|---|---|
| **泛流量** | 不以吸引目标用户为诉求获取的流量 | **≠ 变现**（什么内容吸引什么粉丝） |
| **精准流量** | 精准定位 → 精准内容 → 精准流量 | **= 变现** |
| **IP 流量** | 人设带来的信任流量 | **= 百倍变现** |

- 精准流量链路：精准定位 → 精准内容 → 大数据推给感兴趣用户 → 用户用点赞/收藏/关注完成需求与价值匹配 → 成交。
- **营销人设的本质是获取信任流量**。

### 3. 三类内容，三种分工

**人设类（故事营销 + 事件营销）→ 建立信任｜流量类 → 实现转粉｜案例类 → 完成转化**

- **故事营销**：为事物增加心理价值，改变受众原有观感（向往、同情、共鸣、喜爱）。
- **事件营销**：借会议、评奖、榜单、合作强化人设标签。
- **"十年故事"五要素**：**细节、情感、意外（转折）、金句结尾、励志 BGM**。金句三型：感谢型 / 寄语型 / 感悟型。
- **流量类五要点**：①市场多次验证 ②受众广 ③痛点够痛 ④利他性 ⑤有干货。
- **内容配比**：起号期 流量 50%+/人设 30%/案例 20%；1 万粉后 流量 50%/案例 30%/人设 20%；平稳期案例渐增。
- **干货类内容 ≠ 变现；围绕产品输出的干货内容 = 变现。**
- **一个账号 80% 的粉丝来自 20% 的爆款。**
- **飞轮效应 / 复利拐点**：前期拼命高产到达拐点，之后日更即可；别因为一篇数据不好就停。

### 4. 文案：拆爆款（开头 + 主体 + 结尾）

**9 种开头**：①呈现结果型 ②罗列痛点型（痛 + 方案 + 效果）③引起恐慌型 ④提问型 ⑤讲故事型 ⑥场景呈现型 ⑦反常识型 ⑧制造冲突型（硬组合）⑨直入正题型（主题 + 价值 + 互动）。

**2 大主体**：列点式（平行）、递进式（是什么+为什么+怎么样／案例+原因+方案／第一步→第二步→第三步）。

**5 种结尾**：金句升华、美好祝福、互动提问、总结回顾（表格/思维导图，**提升收藏**）、号召行动。

- **恐慌型开头必须配**：足够吓人 + 具体建议 + 让人相信建议能降低威胁 + 执行方便（《认知操纵》四条件）。
- **峰终定律**（卡尼曼）解释了为什么结尾能拉升互动率。
- **知识 vs 观点**：知识有确定答案，观点只要逻辑自洽——这是反常识内容的理论依据。

### 5. 视频：前五秒决定生死

- **爆款 = 选题 + 封面 + 文案 + 表现力 + 标题**，五项中三项做对就能火。
- **网感三练**：刷低粉爆款（起号前一周每天 3 小时，重点看前五秒）→ 拆爆款（剧情拆开场／vlog 拆选题／口播拆钩子）→ **先猜评论再看评论**。
- **光线优先级**：室外自然光 ＞ 室内自然光（朝窗）+ 补光 ＞ 补光。三点布光 = 主光 + 辅助光 + 轮廓光。
- **景别**：远／全／中景（口播常用）／近景（情绪）／特写（细节）。
- **剪映六步**：导入 → 智能剪口播 → 智能字幕 → 花字 → 音效 → 导出；**先关掉"自动添加片尾"**。
- **镜头表现力的本质 = 自然地做自己**，不是夸张咆哮。

### 6. 起号 7 步

**熟悉 → 定位 → 对标 → 选题 → 文案 → 拍剪 → 复盘**

- **熟悉**：薯管家／薯队长／创作学院／千瓜公众号。
- **定位四问**：你喜欢什么？擅长什么？你被人夸得最多的是什么？你在什么事情上花时间花钱最多？（纸笔写，20 分钟）
- **对标**：20 个 1 万–10 万粉对标 + 新红"低粉爆款排行"近七天。
- **选题**：搭**爆款选题库**。
- **复盘四指标**：**点击率**（封面+标题）｜**完播率**（脚本节奏/时长）｜**观看来源**（搜索流量靠关键词布局）｜**粉丝画像**（是否匹配变现定位）。

### 7. 变现与平台

- **笔记带货两模式**：0 粉开店带店铺产品／1000 粉后开通买手合作赚佣金（通常 10%–30%）。
- **纯小白优先带货**：流量机会多、操作简单、只考核转化不考核爆款。
- **薯店七步**：开店（仅需身份证）→ 保证金可延后 → **热搜词选品** → 一键搬家 → **必须挂商品链接** → AB 测试 → 复盘。
- **聚光 vs 薯条**：聚光需蓝 V（2000 首充）、**按点击计费**、偏广告案例内容；薯条不限主体、按曝光计费（75 元/5000 曝光）、偏知识内容。**用了聚光，引流不算违规。**
- **投流四问**：投什么（有自然出单的优先）→ 怎么投（测时段/城市/年龄）→ 什么品类（细分类目、高客单、有复购）→ 什么时候停（看获客成本与 ROI）。
- **直播三大特点**：以人带货（货物跟着博主走）、注重产品品质、聊天式分享与强烈信任感。

### 8. 品牌账号：七大爆款类型

抽奖福利类｜用户共创类｜品牌联动类｜热点营销类｜玩梗人设类｜产品联名类｜玩梗卖货类

- **五类爆款标题**：直球式（"抽 1 位马铃薯公主送去哈尔滨"）｜紧迫感式（"×××，就在今天！！"）｜玄学式（"被霸总指到的人都中奖！"）｜态度宣告式（"×××，霸总第一个举手"）｜共创宣告式（"因为一条笔记，我们要改版了？！"）。
- **封面三法**：大字海报／实拍图／用户帖子截图。
- **做热点的第一个，不做第二个**；不能做热点的穿堂风，也不能做热点的神经病。
- **抽奖是内容的 1/10，不是 1/2**；抽前预告比抽奖更涨粉。
