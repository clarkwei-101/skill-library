# 速查表（Cheatsheet）

一页纸决策参考。每条都是"什么时候 → 做什么 → 为什么"。

---

## 一、诊断：数据不好先看哪个指标

| 现象 | 根因 | 动作 |
|---|---|---|
| 点击率低 | 封面/标题弱 | 换封面类型（每种试 ≥10 次）、换标题型 |
| 完播率低 | 脚本结构/时长/节奏 | 重写前 5 秒、压缩时长、加讨论点 |
| 有曝光无咨询 | 泛流量 | 砍蹭热点内容，改做精准选题 |
| 爆款但不涨粉 | 缺人设 / 粉丝不精准 | 补人设类内容，查选题与目标客户是否一致 |
| 爆款但不成交 | 干货没挂产品 | 改为围绕产品输出干货、挂商品链接 |
| 粉涨得快掉得也快 | 靠抽奖拉新 | 抽奖只占 1/10，先做内容与人设 |
| 搜索流量少 | 关键词没布局 | 标题/正文/话题嵌入用户搜索词 |

## 二、选题决策

```
①市场多次验证 ②受众基数广 ③痛点够痛 ④利他（少说"我"） ⑤有干货
优先级：选题 > 形式 > 内容（选题决定 80% 流量）

不知道写什么 → 去爆款选题库翻
```

## 七、投流：聚光 vs 薯条

| | 聚光 | 薯条 |
|---|---|---|
| 主体 | 蓝 V 企业号 | 个人/企业专业号均可 |
| 计费 | 按**点击** | 按**曝光**（75 元 / 5000 次） |
| 适合 | 内容一般的商家 | 封面吸睛的内容 |
| 内容偏好 | 广告案例类 | 知识类 |

投流四问：**投什么**（有自然出单的笔记优先）→ **怎么投**（测时段/城市/年龄）→ **什么品类**（细分类目、高客单、有复购）→ **何时停**（看获客成本与 ROI）
实操：手机卡案例 300 进线/100 转化（30%）→ 80% 预算压早、晚两时段。

## 九、告警信号（看到就该停手）

- 发了 3 条数据都差 → 换方向，不是继续改细节（策略需要跑一段时间）
- 笔记爆了但一个咨询都没有 → 选题不精准，别再追爆款
- 粉丝在涨但掉得更快 → 抽奖占比过高
- 文案里"我"字太多 → 自嗨，立刻换用户视角重写
- 形象与身份认知不符（医生不穿白大褂）→ 用户不买单，先修服化道
- 想做新赛道但零经验零资源 → 追别人的钱赚不到，先做熟悉的领域

## 十、品牌号速查

```
七大爆款：抽奖福利 / 用户共创 / 品牌联动 / 热点营销 / 玩梗人设 / 产品联名 / 玩梗卖货
标题五型：直球式 / 紧迫感式 / 玄学式 / 态度宣告式 / 共创宣告式
封面三法：大字海报 / 实拍图 / 用户帖子截图
立人设三步：自来水 → 社会化话题 → 三方交集
玩梗的度：做第一个不做第二个；不做穿堂风，也不做神经病
```

## 十一、心态（决定你能走多远）

- 终局思维：一篇不火，长期可能影响 10–30 万人
- 飞轮/复利拐点：前期拼命高产到达拐点，之后日更一条
- 创作最重要的是流程，而不是灵感
- 他律 + 批量集中，代替每天下班后碎片化生产
- 人生是马拉松不是百米跑，越用力对结果的欲求越高，越难坚持
