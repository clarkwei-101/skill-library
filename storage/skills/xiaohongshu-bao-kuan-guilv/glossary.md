# 术语表

按拼音首字母排序。括号内为章节。

**AB 测试** — 用足够多试验笔记测多款产品、多版封面，一旦出现高流量笔记就批量复制。(Ch7)

**案例类内容** — 第三类内容，作用是完成转化；核心素材是商业成功案例：用户服务前后对比、用户真实好评反馈。(Ch2, Ch6)

**白大褂与服化道** — 账号人设要符合大众对该身份的认知（医生穿白大褂、老师戴眼镜），否则用户不愿买单。(Ch1)

**爆款是重复的** — 全书第一方法论：爆款可被拆解、可被复制，靠重复已被验证的结构而非靠灵感。(Ch1)

**爆款公式** — 100% 成功 = 70% 和爆款类似 × 足够多的试验品。(Ch1, Ch2, Ch7)

**拆爆款** — 提升文案功底的核心动作：把文案拆成开头、主体、结尾三部分，分别分析其机制。(Ch3)

**场景呈现型开头** — 切入用户熟悉的场合，描述"拥有后的美好画面"或"没有后的糟糕画面"，使用户产生画面感与需求。(Ch3)

**创意封面** — 用于干货类内容的封面类型，强调设计感；每种类型需起码试 10 次。(Ch5)

**底层操作系统是情绪** — 梁宁：人的情绪主要包括愉悦、痛苦、恐惧；抓住情绪就收获注意力。(Ch3)

**电商买手** — 具备专业知识和深刻理解用户需求的代购者，在其与用户、商品之间建立信任关系的电商模式。(Ch7)

**低粉爆款** — 粉丝量不高但数据优秀的笔记；起号期比大博主爆款更有参考价值，因为路径可复制。(Ch4, Ch5)

**定位** — 《定位》理论：定位不是创造新事物，而是操控心智中已经存在的认知，重组已存在的关联认知。(Ch1)

**飞轮效应 / 复利拐点** — 静止的飞轮需反复施力，越过临界点后越转越快；对应内容复利拐点：前期高产到达该点后，后期日更即可。(Ch1, Ch2)

**复盘四指标** — 笔记点击率、完播率、观看来源、粉丝分析。(Ch5)

**干货类内容** — 提供可执行知识的内容；**不等于变现**，围绕产品输出的干货才等于变现。(Ch2)

**黄金一小时** — "起床后黄金一小时"，被市场多次验证的爆款选题；复盘一姐靠它获赞 20 万、收藏 15 万。(Ch1, Ch2)

**获客白名单** — 聚光平台让商业引流不再算违规，故被称为小红书私信"白名单"。(Ch7)

**技术参数** — ISO（感光度）、S（快门速度）、EV（曝光补偿）、AF（对焦）、AWB（白平衡）。(Ch4)

**剪映六步** — 导入素材、智能剪口播、智能字幕、添加花字、添加音效、导出设置。(Ch4)

**金句结尾三型** — 感谢型、寄语型、感悟型。(Ch2, Ch3)

**刻板印象** — 人们整合信息与经验后对特定对象形成的既定认知模式；账号人设须符合它。(Ch1, Ch2)

**冷启动** — 账号或粉丝群从零开始的过程；洁柔通过建群让粉丝每天为品牌说话形成正向循环。(Ch8)

**逻辑自洽** — 观点类内容只要围绕主题、逻辑闭环自圆其说即可，不要求唯一答案。(Ch3)

**买手时代** — 2023 年小红书宣布进入买手时代，把更多资源投入买手电商。(Ch7)

**矩阵** — 搭建多个账号增加内容曝光度，用频次对冲单账号的不确定性。(Ch6)

**千瓜数据 / 新红 / 蝉小红 / 灰豚数据** — 数据分析工具，用于看低粉爆款排行与大盘报告。(Ch4, Ch5)

**前五秒** — 视频的第一道及格线；留不住用户则爆款与你无关。(Ch4)

**情绪三角** — 愉悦、痛苦、恐惧。(Ch3)

**景别五分类** — 远景 / 全景 / 中景（口播常用）/ 近景（情绪）/ 特写（细节）。(Ch4)

**三类流量** — 泛流量、精准流量、IP 流量。(Ch1)

**三类内容** — 人设类、流量类、案例类。(Ch2, Ch6)

**内容配比** — 流量类/人设类/案例类在不同账号阶段的比例。(Ch2)

**内容即产品，产品即营销** — 一篇优质笔记同时完成引流、营销、立人设。(Ch6)

**平行/递进** — 主体写作的两种骨架：列点式（点与点平行）与递进式（有先后承接）。(Ch3)

**私域构建** — 品牌建粉丝群做冷启动与日常互动，把公域流量沉淀为可反复触达的用户。(Ch8)

**素人** — 无机构背书的普通创作者；"十年故事"选题的典型主体。(Ch2)

**标题五型** — 直球式、紧迫感式、玄学式、态度宣告式、共创宣告式。(Ch8)

**头部思维** — 找到细分赛道并排到第一，因为人们只记住第一名。(Ch1)

**网感** — 对内容的预判力 + 对用户群体的感知力；靠刷低粉爆款、拆爆款、猜评论三种方法练。(Ch4)

**文案三段拆解** — 开头、主体、结尾。(Ch3)

**系列化内容** — 让用户有追剧乐趣的内容结构，如"21 天逆袭人生系列"。(Ch5, Ch7)

**选品中心** — 买手合作页面内的选品入口，可选定向邀请、直接选品或免费拿样。(Ch7)

**引起恐慌型开头** — 罗列痛点问题 + 不改变的巨大不良后果 + 致以改变的具体方法；依据恐惧心理与《认知操纵》四条件。(Ch3)

**营销 4.0** — 1.0 上央视 → 2.0 多屏幕 → 3.0 相信人 → 4.0 算法 + 口碑。(Ch8)

**硬组合** — 把两个不相关或相反的词硬生生组合在一起并解释清楚，用于制造冲突型开头。(Ch3)

**营销人设 = 获取信任流量** — 人设的变现本质；有 IP 能带来溢价并扩大选择范围。(Ch1)

**十年故事五要素** — 细节、情感、意外（转折）、金句结尾、励志 BGM。(Ch2)

**制作高信息密度封面** — 小红书用户偏好信息密度大的封面，密密麻麻的封面更容易火。(Ch2)

**直入正题型开头** — 主题 + 能带来的价值 + 互动；让用户快速知道主题与收益。(Ch3)

**直球式标题** — "抽 1 位马铃薯公主送去哈尔滨"式，开门见山、简单明确。(Ch8)

**制造成本最低的共鸣** — 细节（时间、地点、人物、情节、心理活动与五感）。(Ch2)

**终局思维** — 做一件事时思考其终局：短期一篇不火，长期一篇爆款影响 10–30 万人。(Ch1)

**自嗨** — 内容只表达自己想说的、忽视用户价值的陷阱；自检方法：数"我"字数量。(Ch2)

**自定位** — 用四问（喜欢/擅长/被夸最多/花时间花钱最多）确定自己的账号定位。(Ch5)

**总裁人设** — 洁柔的"霸道总裁"人设，通过古龙香、#霸道总裁 话题与品牌受众做三方交集得出。(Ch8)

**罗列痛点型开头** — 揭露用户的"痛" + 给出解决方案 + 解决效果；公式同"怕上火，喝王老吉"。(Ch3)

**爆款选题库** — 把对标账号高数据选题按模板沉淀，灵感枯竭时翻库。(Ch5)

**违禁词检测** — 用零克查词、句易网、红薯编辑器在发布前检测违规词，避免限流。(Ch3)

**三高一低** — 小红书电商特征：高转化率、高客单价、高复购率、低退货率。(Ch7)

**三点布光** — 主光（侧前方 45°）+ 辅助光（侧前方 45–65°）+ 轮廓光（侧后方高于摄像机）。(Ch4)

**专业杀死流量，演员成就爆款** — 有流量的博主往往因为"长得就像做这行的人"。(Ch1, Ch2)

**选题 > 形式 > 内容** — 一个好选题能决定 80% 的流量。(Ch1)
